# План упрощения (2026-10-30)

Жалоба: «слишком много лишнего, непонятно, что куда вносить».
Ответы: траты чаще всего по чеку через Claude; обе валюты нужны; остальное (позиции
чека и фото, желаемые покупки, долги людям, прогноз закупок) — не главное.

## Правило: три действия — три места

| Что хочу сделать | Куда идти | Что ввожу |
|---|---|---|
| **Записать трату** | Операции → «+» (или быстрый расход на Главной, или «Импорт чека из Claude» там же, вверху) | сумма, валюта, категория, дата |
| **Запомнить, что надо заплатить или получить к дате** | Платежи → «+ Платёж» | что, сумма, категория или источник, когда (один раз / каждый месяц / каждый год), дата |
| **Задать план на месяц** | Бюджет → категория или источник | план, лимит |

Всё остальное — либо считается само, либо спрятано в «Дополнительно».

## Что убирается с глаз (не удаляется, данные остаются)

1. **«Ещё»** — остаются 6 пунктов: Отчёты, Категории, Банки, Курсы, Резервная копия, Настройки. Под свёрнутым «Дополнительно»: Продукты, Отчёт по продуктам, Прогноз закупок, Желаемые покупки, Долги людям, Расписания платежей.
2. **Форма траты**: только сумма, валюта, категория → статья, дата, комментарий. «Магазин», «Позиции чека», «Фото» — показываются только если они уже есть у операции (из импорта) или по кнопке «Подробнее».
3. **Импорт чека из Claude** — заметная кнопка вверху «Операций» (сейчас спрятан в «Ещё»).
4. **Бюджет**: в строке категории — только *план / факт* и полоса лимита; подсказки «0,30 € в день (4 дня)», «статей: 2», «работодатель не указан» убираются (они на экране категории). Копирование месяца, «убранные из месяца», желаемые — в меню «⋯» справа от месяца.
5. **Экран категории**: одна карточка «План ___ Лимит ___ [Сохранить]» (валюта — переключатель рядом, без отдельного поля «валюта ввода»); ниже статьи (если есть) и платежи (если есть) — иначе одна строка «+ статья · + платёж»; «Операции за месяц»; «Убрать из бюджета» — в «⋯».
6. **Источник дохода**: одна карточка вместо шести блоков: «Freedom · платят 10-го за прошлый месяц [изменить]» · «План в месяц 615 000 ₸ · каждый месяц [изменить]» · «Получено в октябре: 0 ₸ [Получила]» · «Долг: 615 000 ₸, просрочено 18 дн.». Таблица по месяцам и поступления с датой — под «Подробнее».
7. **Форма платежа**: 5 полей — что, сумма + валюта, категория / источник, когда (один раз / каждый месяц / каждый год), дата. Для «Кредитов» ещё банк и число платежей. Остальное (каждую неделю, свой период, дата окончания, «ждать отметки», сумма кредита) — под «Дополнительно». «Ждать отметки» по умолчанию включено.
8. **Главная**: быстрый расход показывает 6 самых частых категорий и кнопку «ещё»; блок лимитов — одной строкой.

## Что не меняется
Данные, резервные копии, расчёты, тесты (104). Всё спрятанное открывается в один клик.

## Этапы
1. «Ещё» и «Дополнительно», форма траты, импорт на виду.
2. Бюджет: строки, экран категории, источник дохода.
3. Форма платежа.
4. Главная, сквозная проверка, обновление памятки.
