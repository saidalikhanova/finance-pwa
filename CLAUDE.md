# Проект: личное финансовое приложение (PWA)

Полное техническое задание: `docs/TZ-finance-pwa.md`. Это единственный источник требований. Прогресс ведётся в `PROGRESS.md`.

## Порядок работы

- Работать строго по этапам из раздела 8 технического задания. Выполнять только текущий этап, не переходить к следующему без подтверждения пользователя.
- Перед началом этапа кратко описать план и список файлов, которые будут созданы или изменены.
- После этапа: запустить тесты, запустить приложение, кратко описать результат, перечислить, что пользователю проверить на телефоне, обновить `PROGRESS.md`, сделать коммит в git.
- Не добавлять функции, которых нет в техническом задании. Если требование неясно или противоречит другому, остановиться и задать вопрос.
- Пользователь не разработчик: объяснять результат простым языком, без лишней терминологии.

## Технические правила

- Приложение — PWA, работает без интернета; данные хранятся локально в IndexedDB; серверной части нет.
- Единственный внешний запрос — получение курса Национального банка Казахстана.
- Денежные суммы хранить целыми числами в минимальных единицах (центы, тиыны). Не использовать числа с плавающей запятой для денег.
- Схема базы данных версионируется; для каждого изменения схемы писать миграцию. Обновление приложения не должно удалять или портить данные пользователя.
- Формат файла резервной копии содержит номер версии; импорт проверяет структуру и версию до изменения данных.
- Интерфейс на русском языке, сначала мобильный экран, светлая и тёмная темы.
- Использовать простой поддерживаемый стек без лишних зависимостей.

## Тестирование

Обязательные автоматические тесты для:
- денежных расчётов и пересчёта евро/тенге по курсу;
- лимитов категорий и показателя «можно тратить в день»;
- повторяющихся платежей (в том числе пропущенные периоды, срок окончания, количество платежей);
- копирования бюджета;
- прогноза закупок;
- экспорта, импорта и восстановления резервной копии;
- импорта данных из чата (формат JSON с позициями).

## Стиль документов и интерфейса

Деловой стиль, без сленга. Если нужного термина нет, спросить пользователя, а не придумывать самостоятельно.
