# Финансы — личное приложение (PWA)

Требования: `docs/TZ-finance-pwa.md`. Ход работы: `PROGRESS.md`.

Приложение собрано без инструментов сборки: обычные HTML, CSS и JavaScript-модули.
Установка Node.js не требуется.

## Адрес приложения

https://saidalikhanova.github.io/finance-pwa/ — GitHub Pages из ветки `main` (корень репозитория).
После `git push` сайт обновляется за 1–2 минуты; установленное приложение подхватит новую версию при следующем открытии, если увеличен `CACHE_VERSION` в `sw.js`.

## Установка на телефон

- iPhone (Safari): открыть адрес → кнопка «Поделиться» → «На экран „Домой“».
- Android (Chrome): открыть адрес → меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).

## Запуск на компьютере

В папке проекта:

```bash
python3 scripts/serve.py
```

Затем открыть в браузере http://127.0.0.1:5193/

## Тесты

Открыть в браузере http://127.0.0.1:5193/tests/ — результат проверок показывается на странице.

## Обновление приложения

После любого изменения файлов приложения увеличить `CACHE_VERSION` в `sw.js`,
иначе установленное приложение продолжит показывать старую версию.
