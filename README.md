# Финансы — личное приложение (PWA)

Требования: `docs/TZ-finance-pwa.md`. Ход работы: `PROGRESS.md`.

Приложение собрано без инструментов сборки: обычные HTML, CSS и JavaScript-модули.
Установка Node.js не требуется.

## Запуск на компьютере

В папке проекта:

```bash
python3 -m http.server 5193 --bind 127.0.0.1
```

Затем открыть в браузере http://127.0.0.1:5193/

## Тесты

Открыть в браузере http://127.0.0.1:5193/tests/ — результат проверок показывается на странице.

## Обновление приложения

После любого изменения файлов приложения увеличить `CACHE_VERSION` в `sw.js`,
иначе установленное приложение продолжит показывать старую версию.
