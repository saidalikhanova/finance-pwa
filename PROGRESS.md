## Журнал

### 2026-10-18 — этап 1

Решение по стеку: без Node.js и инструментов сборки — обычные HTML, CSS и JavaScript-модули (вариант А, выбран пользователем). Локальный запуск через Python (`python3 -m http.server`). Тесты выполняются страницей `tests/` в браузере.

Сделано:
- оболочка приложения с пятью разделами (Главная, Операции, Бюджет, Отчёты, Ещё), светлая и тёмная темы;
- манифест и иконки для установки на домашний экран (iOS и Android);
- сервис-воркер: приложение открывается без интернета (проверено: при остановленном сервере страница загружается из кэша);
- локальная база IndexedDB с версионируемой схемой и миграциями (пока одна таблица `settings`);
- тесты базы: 6 проверок, все проходят.

Не проверено: установка на домашний экран и работа без интернета на реальном телефоне (требует публикации на GitHub Pages — этап 10, либо ранее по решению пользователя).
